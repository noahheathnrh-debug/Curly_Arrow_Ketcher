# MnemoNexus Add-on

The owner requires the independently installable teaching experience to live in
this repository, under `mnemonexus/`. This supersedes the earlier placement advice
that all trainer teaching code must live only in the sibling trainer repository.
The sibling repository remains intact; editor domain code still owns chemistry
and rendering, while the subpackage owns prompts, checking and the host adapter.

The subpackage consumes the existing built core/react package exports and the
separate public SDK. It imports no private MnemoNexus application code. Its initial
manifest exposes six guided mechanisms plus the restored imported level browser,
no graph binding and local study storage permission. Structures use the enforced arrow-only
capability profile. Product construction is explicit optional future work.

Version 0.3.0: standalone opens LevelBrowser; study opens the exact offered puzzle
and persists KET/step/attempts/hints through the public host bridge. Imported corpus
is a declared asset. Old LP-to-atom answers become directed new-bond descriptors;
ambiguous migrating bond endpoints and gaps in source step numbering withhold the
whole level. Current count: 255 imported levels / 489 exercises, six guided levels.
Study uses only the reviewed guided offers. Recall binding and real lecture-derived
mechanism admission remain open. No mastery or graph writes are granted.

Arrow-only tasks activate existing focused controls at initialization. Action
status hides authoring actions; App omits bottom/template and right/atom palettes
and collapses their grid tracks; the full-control filter toggle is hidden. Core
capability enforcement remains the security boundary. Preserve baked KET layout
and the editor's existing automatic fit/centering. Full editor mode is unaffected.
